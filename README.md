# practica-1-tienda
Practica 1: Desarrollo de una Tienda Web de Calzados y Ropa 

Idea del Proyecto
El proyecto consiste en el desarrollo de una página web de catálogo digital interactivo como herramienta de ventas para un negocio de importación de ropa y calzado que actualmente vende a través de Facebook Marketplace. El sitio resuelve la falta de un espacio centralizado y detallado donde los usuarios puedan consultar el stock en tiempo real (fotos, precios, tallas y colores disponibles), automatizando la generación de pedidos al dirigir la reserva directamente a WhatsApp con el detalle estructurado del producto, fecha, hora y punto de entrega. Esto elimina la comunicación repetitiva, reduce errores en la toma de pedidos y agiliza la concreción de ventas para el negocio.
